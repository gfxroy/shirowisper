After you download

macOS blocks an app it has not seen before. The first open takes a minute.

  1. Unzip the download and move ShiroWisper into Applications.
  2. Right-click ShiroWisper, choose Open, then Open again. If macOS still blocks it, open System Settings → Privacy & Security and choose Open Anyway.
  3. Open ShiroWisper and allow the microphone.
  4. In System Settings → Privacy & Security → Accessibility, turn ShiroWisper on. If a row named Python is listed, leave it off.
  5. Quit ShiroWisper and open it again. The hotkey starts listening after that.
  6. In Settings, paste a Gemini key from Google AI Studio. Choose Test key, then Save settings.

If it hears you and nothing pastes, turn Accessibility off and on, then quit and reopen.

Speech goes to Google with that key. The key stays on your Mac, in a file only your account can read. Dictation is about half a cent a minute.
