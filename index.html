Mac

01

Drag it across

Open the disk image and drop ShiroWisper on the Applications folder.

02

Open it once

In Applications, right-click ShiroWisper, choose Open, then Open again. If macOS still blocks it, choose Open Anyway in Privacy & Security.

03

Allow it

Turn on the microphone and Accessibility. Leave any row named Python off. Quit ShiroWisper and open it again.

04

Add your key

Paste a Gemini key from Google AI Studio. Hold Fn to dictate. Speech goes to Google. The key stays on your Mac.

If it hears you and nothing pastes, turn Accessibility off and on, then quit and reopen. Dictation is about half a cent a minute.

Windows

01

Unzip it

Open the zip and leave the ShiroWisper folder where you want it.

02

Open it

Double-click ShiroWisper. If Windows says it protected your PC, choose More info, then Run anyway.

03

Allow the microphone

Windows asks once. Leave the ShiroWisper window open.

04

Add your key

Paste a Gemini key from Google AI Studio. Hold Right Alt to dictate. Double-tap it for hands-free. F9 edits a selection.

Speech goes to Google. The key stays on this PC. Dictation is about half a cent a minute.

Linux

01

Extract it

Use the Linux download on most PCs. Use Linux ARM on an ARM laptop or a Raspberry Pi.

02

Install it

Run install.sh. It can ask for your password once, to install the microphone and clipboard tools, and adds ShiroWisper to your apps.

03

Open it

Start ShiroWisper and allow the microphone. Leave the window open.

04

Add your key

Paste a Gemini key from Google AI Studio. Hold Right Alt to dictate. Double-tap it for hands-free. F9 edits a selection.

If the hotkey does nothing, the desktop is blocking global keys. An X11 session lets them through. Dictation is about half a cent a minute.
